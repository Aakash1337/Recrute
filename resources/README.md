# resources/ (your inputs, gitignored)

| Path | What goes here |
|---|---|
| `resume/` | Your **mega resume**: everything you've done, in any format (`.md`, `.docx`, `.pdf`, `.txt`). Several files are fine. It gets structured into `data/profile.yaml`, which you review. |
| `cover_letters/` | Past cover letters, used as voice and style samples. |
| `writing/` | Optional: other writing samples in your own voice. |
| `answers.yaml` | Your answer bank. `recrute init` creates it from `answers.example.yaml`; fill it in. |
| `criteria.yaml` | What to search for and filter out. `recrute init` creates it from `criteria.example.yaml`. |

The system never invents facts. Everything it writes about you comes from these files.
