Access

Opening Recrute from your phone, another computer or the browser extension.

On this computer Recrute opens without signing in. Anywhere else it asks for this access token once, then remembers the device for 90 days.

Treat it like a password: anyone on your network who has it can use Recrute as you. You can also see it by running recrute token in a terminal on this computer.
